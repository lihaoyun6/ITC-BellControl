# ITC 广播控制台

针对 ITC 品牌校园数字广播系统开发的轻量级 Web 替代面板。   

<img width="2331" alt="Image" src="https://github.com/user-attachments/assets/21643116-47d5-4c06-8c05-8792b4ec62da" />

## 核心特性

- **即开即用**

    项目采用纯静态实现，无构建流程，无第三方外部依赖，开箱即用。

- **考试模式编排**  

  用户只需添加考试日程，控制台会自动计算考试日程与日常铃声计划的重合度并自动进行闪避，避免了人工修改疏漏导致考试进程被意外铃声干扰的情况。  

- **基于浏览器的实时对讲**  

  无需购买并配置数字拨号话筒，在浏览器网页中即可调用本机麦克风对任意终端或群组进行实时对讲，或实时音频播放。 

- **移动端全适配**  

  完全适配竖屏触摸操作逻辑，在手机上即可完成日常的广播调控工作，大大提升工作效率。  
  
- **终端任务反查**  

  快速查询某(些)终端在某一天会执行哪些铃声，一眼穿透所有任务列表，全局总览快速发现异常项目。


## 部署说明

1. 从本项目 [发布页面](https://github.com/lihaoyun6/ITC-BellControl/releases/latest) 下载压缩包并将下载好的压缩包整个解压到某目录中 (例如 `D:\ITC-BellControl`)   
2. 进入解压好的文件夹: 

  - Windows双击`run_win.bat`
 - Linux执行`./run_linux.sh`
 - macOS 双击`run_mac.command`  

	> 脚本默认将在 **8182** 端口启动网页服务，并在 **8181** 端口运行 `play-agent` 代理。  
	> 注: `play-agent` 程序主要用于驱动浏览器内的 "实时对讲" 和 "在线播放" 功能。  
	
3. 脚本将会自动打开浏览器并访问管理面板，如果浏览器没有自动启动，可以手动访问 [http://127.0.0.1:8182/](http://127.0.0.1:8182)

## 注意事项

1. 本面板仅提供排程编排与系统配置管理，实际音频播放、流媒体分发及硬件触发均由原厂广播服务独立执行。
2. 本面板基于原厂 `v2` 版本接口规范开发。如广播系统接口发生版本更迭，可能需要同步适配请求格式。
3. 本面板不内置越权鉴权机制，业务操作权限完全由广播服务器原厂账号权限决定。
