# ITC 广播控制台

针对 ITC 品牌校园数字广播系统开发的轻量级 Web 替代面板。
> 本面板不对基础功能 (例如设备管理或系统设置等) 重复实现, 只解决日常使用中的某些痛点。   
> 项目采用纯静态实现，无构建流程，无第三方外部依赖，开箱即用。

## 核心特性

- **考试模式编排**  

  用户只需添加考试日程，控制台会自动计算考试日程与日常铃声计划的重合度并自动进行闪避，避免了人工修改疏漏导致考试进程被意外铃声干扰的情况。  

- **移动端全适配**  

  完全适配竖屏触摸操作逻辑，在手机上即可完成日常的广播调控工作，大大提升工作效率。  
  
- **终端任务反查**  

  快速查询某(些)终端在某一天会执行哪些铃声，一眼穿透所有任务列表，全局总览快速发现异常项目。


## 运行模式

根据使用终端的数量与配置共享需求，提供两种运行模式：

| 维度 | 单机模式 | 服务器模式（推荐） |
|---|---|---|
| **适用场景** | 单台电脑固定使用 | 手机、办公室电脑等多设备协同管理 |
| **外部组件** | **无需任何组件** | 需要配套服务器软件（推荐 dufs） |
| **配置存储** | 存储在当前浏览器本地缓存 | 持久化存储于服务端的 `config.json` |
| **数据同步** | 不支持跨设备、跨浏览器同步 | 所有终端打开即为统一配置 |

> 无论采用哪种模式，向广播服务器发起请求所需的认证凭据（Token）均在各终端浏览器内独立生成与保存。  
> 服务端均不记录账户密码

## 部署说明

### 模式一：单机模式（无需安装）

1. 从本项目 [发布页面](https://github.com/lihaoyun6/ITC-BellControl/releases/latest) 下载压缩包并解压其中的 `bell-panel` 文件夹。
2. 直接双击打开其中的 `index.html` 文件。
3. 在登录界面输入广播服务器地址、端口及管理员凭据即可使用。

> 此模式下，面板的自定义分组与预设参数仅保存在当前浏览器的本地存储中，清理浏览器缓存或更换设备会导致本地偏好配置重置。

---

### 模式二：服务器模式（推荐）

推荐直接部署在**运行 ITC 服务端的主机**或内网常开的服务器上。 借助轻量级服务器 `dufs` 同时实现页面托管。

1. 从本项目 [发布页面](https://github.com/lihaoyun6/ITC-BellControl/releases/latest) 下载压缩包并将下载好的压缩包整个解压到某目录中 (例如 `D:\ITC-BellControl`)  
2. 访问 [dufs v0.40 发布页](https://github.com/sigoden/dufs/releases#release-v0.40.0)，下载对应版本并将其中的 `dufs.exe` 或 `dufs` 文件解压到刚刚的文件夹中。  
3. 执行对应平台的运行脚本：  
	
	> Windows双击`run_win.bat`; Linux执行`./run_linux.sh`  
	> 脚本默认将在 **82 端口**启动监听（为避免与原厂后台默认的 81 端口冲突，修改脚本里的 `-p` 参数可更换端口）

4. 确保系统防火墙放行 TCP 82 端口。并可根据需求自行设置开机自启。  
5. 客户端访问 `http://<服务器IP>:82` 然后在登录界面输入广播服务器地址、端口及管理员凭据即可使用。  

## 注意事项

1. 本面板仅提供排程编排与系统配置管理，实际音频播放、流媒体分发及硬件触发均由原厂广播服务独立执行。
2. 本面板基于原厂 `v2` 版本接口规范开发。如广播系统接口发生版本更迭，可能需要同步适配请求格式。
3. 本面板不内置越权鉴权机制，业务操作权限完全由广播服务器原厂账号权限决定。
